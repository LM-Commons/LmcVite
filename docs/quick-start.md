LmcVite provides Laminas View helpers that creates the necessary scripts to load Vite assets.

## Requirements

- PHP 8.3 or higher
- Laminas View v2 or v3

## Installation

LmcVite only officially supports installation through Composer.

Install the module:

```sh
$ composer require lm-commons/lmc-vite
```

You will be prompted by the Laminas Component Installer plugin to inject the
component into your `config/config.php` file.
