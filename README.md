## Requirements

- PHP 8.2 or higher

## Installation

LmcVite only officially supports installation through Composer. For Composer documentation, please refer to
[getcomposer.org](http://getcomposer.org/).

Install the module:

```sh
$ php composer.phar require lm-commons/lmc-vite
```
Customize the module by copy-pasting
the `config/vite.global.php.dist` file to your `config/autoload` folder.
